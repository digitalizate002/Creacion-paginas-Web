Las SPA: aplicaciones de una sola página

Una SPA (Single Page Application) carga un único documento HTML y cambia su contenido con JavaScript, sin recargar la página al navegar.

Cómo funciona

El navegador descarga una sola vez el HTML, el CSS y el JavaScript. Después, al pulsar un enlace, el script pide solo los datos necesarios y reescribe la parte de la pantalla que cambia.

Ventajas

  • Navegación rápida y fluida tras la primera carga.
  • Sensación parecida a una aplicación de móvil.
  • Cabecera y menú que no se vuelven a cargar.

Inconvenientes

  • Primera carga más pesada por el JavaScript.
  • SEO más difícil si el contenido solo existe tras ejecutar el script.
  • Hay que cuidar el botón «atrás», el foco del teclado y los lectores de pantalla.

SPA frente a web de varias páginas

Web de varias páginas

Cada URL es un archivo HTML. Es sencilla, funciona sin JavaScript y los buscadores la leen sin problemas.

Ideal para: webs informativas, blogs y portfolios.

SPA

Una sola página que se transforma según lo que hace la persona usuaria. Necesita JavaScript y una buena estrategia de SEO.

Ideal para: paneles de control, editores y herramientas que se usan durante mucho tiempo.

Qué hemos elegido en este proyecto

Esta web usa varias páginas HTML y CSS porque el contenido es informativo, se publica en un alojamiento estático y queremos que cargue rápido y se indexe bien sin depender de JavaScript. Una SPA tendría sentido si la web creciera hacia una herramienta interactiva.

Cómo optimizar una SPA

  • Dividir el JavaScript en partes y cargar solo lo que cada vista necesita.
  • Dar a cada vista su propia URL, título (title) y descripción.
  • Generar el HTML en el servidor o en la compilación (SSR o prerenderizado) para los buscadores.
  • Mover el foco al nuevo contenido y anunciar el cambio de vista a los lectores de pantalla.
